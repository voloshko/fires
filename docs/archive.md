# Выгрузка многолетнего архива FIRMS

Оперативный контур собирает историю через Area API с параметром даты (SPEC-4),
но эта глубина ограничена. **Измерено 18.09.2026** бинарным поиском по границе:

| | |
|---|---|
| Данные доступны с | **2026-07-01** |
| Глубина на дату замера | **79 суток** |
| За границей API отдаёт | **валидный CSV с нулём строк**, не ошибку |

Последнее — самое важное. Наивный цикл по датам построил бы «десятилетнюю
историю» из пустых ответов, и фильтр персистентности отрапортовал бы «факелов не
найдено» вместо «данных нет». Проверить границу заново:

```bash
set -a && . ./.env && set +a && python3 -m src.archive probe --config config/krasnoyarsk.toml
```

Граница движется вперёд со временем — замер устаревает.

## Ручной шаг: получение выгрузки

**Автоматизировать целиком нельзя.** FIRMS Archive Download — не REST API:
запрос подтверждается кодом на почту, а ссылка на готовый архив приходит
письмом. Эти шаги выполняются вручную; ниже — что именно делать.

1. Открыть https://firms.modaps.eosdis.nasa.gov/download/
2. Задать область. Для Красноярского края — bbox `82,51,109,78`
   (запад, юг, восток, север). На карте это рисуется рамкой либо вводится
   координатами.
3. Выбрать источники. Глубина архива у каждого своя:

   | Источник | Доступен с | Разрешение |
   |---|---|---|
   | MODIS Collection 6.1 | ноябрь 2000 | 1 км |
   | VIIRS S-NPP | январь 2012 | 375 м |
   | VIIRS NOAA-20 | апрель 2018 | 375 м |
   | VIIRS NOAA-21 | январь 2024 | 375 м |
   | Landsat | июнь 2022 | 30 м |

   **Landsat по России данных не даёт** — продукт строится из прямого приёма
   станции USGS EROS и покрывает только Северную Америку (`docs/TZ.md` §3.1).
   Запрашивать его для края бессмысленно.

4. Задать диапазон дат и формат CSV.
5. Подтвердить запрос кодом, пришедшим на почту.
6. Дождаться письма со ссылкой и скачать архив.

## Загрузка выгрузки

```bash
python3 -m src.archive load --config config/krasnoyarsk.toml \
    --input ~/Downloads/fire_archive_SV-C2_*.csv
```

Принимаются CSV и ZIP; сенсор определяется по имени файла (`SV-C2` — S-NPP,
`J1V-C2` — NOAA-20, `J2V-C2` — NOAA-21, `M-C61` — MODIS), либо задаётся
`--sensor`. Команда печатает состав по годам, сенсорам и типам источника и
докладывает детекции в базу.

## Чем архивные данные отличаются от оперативных

Выгрузка несёт две колонки, которых нет в NRT-потоке:

- **`version`** — `2.0` у Standard Processing против `2.0NRT` у оперативных.
  Продукты пересчитаны с уточнённой геопривязкой. Смешивать их в статистике без
  пометки нельзя; в базе поле сохраняется, а `Detection.is_archive` его
  разбирает.
- **`type`** — 0 растительность, 1 вулкан, **2 стационарный наземный
  источник**, 3 офшор. Класс 2 — ровно то, что SPEC-4 вычисляет
  персистентностью за 14 суток, только здесь проставлено NASA. Это делает
  архив источником проверочной разметки для фильтра факелов.

Ключ уникальности детекции — сенсор, координаты и время; версия в него не
входит. Поэтому одна и та же точка, пришедшая обоими путями, останется одной
строкой, а не задвоится.
