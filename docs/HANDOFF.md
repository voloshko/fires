# Handoff: соревновательный контур КосмоХакатона (AF + BS)

Дата: 2026-09-19. Ветка `main`, зеркала `origin` (GitHub) и `gitverse`.
Читать вместе с [CLAUDE.md](../CLAUDE.md) (дисциплина спек и receipt'ов) и
[evidence/hypotheses.md](../evidence/hypotheses.md) (журнал ~50 гипотез с числами).

## 1. Что делаем

Два модуля одной проверяющей системы: **AF** — активное горение по VIIRS
(256×256, F1), **BS** — площадь и степень поражения гари по Sentinel-2
(512×512, IoU_burn и mIoU по 3 классам). Score = 0.35·F1_af + 0.35·IoU_burn +
0.30·mIoU_sev, **микро-усреднение по пулу пикселей**. Ответ — один
`submission.csv` (447 строк RLE), собираемый офлайн `inference.py`.

Правило, которое нельзя нарушить: **FIRMS / VNP14 / MOD14 для тестовых ответов
запрещены** — дисквалификация. `inference.py` читает только каталог чипов и
`models/`. Для обучения на исторических данных эти продукты разрешены.
Тестовые GeoTIFF без геопривязки — ничего внешнего для теста не подтянуть и не
пытаться.

## 2. Где стоим (аналоги на 144 чипах, замер на 35 настроечных вне обучения)

| компонента | порог | сейчас | как получено |
|---|---:|---:|---|
| AF F1 | 0.599 | **0.905** (OOF, 336 чипов) | бустинг по пикселю с окном 15×15, граница 0.985 |
| BS IoU_burn | 0.390 | **0.761** (по чистому небу 0.774) | ансамбль сетей + бустинг 0.4, правила по разметке |
| BS mIoU_sev | 0.155 | **0.722–0.726** | то же |

Взвешенная BS-метрика (0.35·IoU + 0.30·mIoU)/0.65: старт раунда 0.589 →
**0.743** (+26 %). Цель пользователя была +30 % (0.766) — не достигнута;
причины в журнале (65 % ложной гари — отдельные объекты, неотличимые по снимку;
83 % пропусков — кромка).

**Разброс сида 0.004 взвешенно. Всё меньше 0.005 — шум, решения по нему не
принимаются.** Каждое правило проверяется на половинах 17/18 настроечных чипов:
подобрано на одной — измерено на другой.

### Что дало прибавку (по IoU_burn)
гарь под облаками не обнуляется **+0.122** · полный чип 512 +0.057 · глубина
4→6 +0.046 · контекстные окна +0.030 · фильтр чужих пожаров (>125 пикс. от
главного пятна) **+0.019** · ноль только под SCL 0/1/3/9/11 +0.016 · ансамбли
+0.015 · оптика (11 каналов) вместо 19 — лучшие одиночные сети.

### Что отвергнуто (не проверять повторно)
Признаки: RdNBR, разброс SWIR, окно 31, радар «после» (в бустинге и в сети),
канал маски. Обучение: ширина, rot90, Lovász, граничный вес, Boundary DoU,
глубокий надзор, пирамида PSP, копирование-вставка, псевдоразметка, тень вне
потери, ImageNet-кодировщики MiT-B0/B2 (SPEC-22, вторая пара в очереди),
Prithvi-EO-2.0 в трёх режимах (SPEC-23, 0.61). Правила: пороги, расширение
кромки, дыры, размерный и относительный фильтры пятен, медиана, калибровка
классов, стекинг, жадный отбор членов ансамбля, TTA-8.

## 3. Где мы среди мировых моделей

Сравнение приблизительное — наборы разные. IoU бинарной гари:

| работа | данные | IoU |
|---|---|---:|
| Prithvi-EO-2.0-300M | HLS Burn Scars, 804 сцены, 30 м, США | 0.875 |
| U-Net + MiT-B0 (ImageNet) | CEMS-Wildfire, 500+ сцен S2, Европа | **0.779** |
| SegNext | CEMS-Wildfire | 0.767 |
| **мы, чистое небо** | 224 чипа, 20 м, степь | **0.774** |
| **мы, все пиксели (метрика кейса)** | | 0.761 |
| DeepLabV3+ | CEMS-Wildfire | ≈0.72 |

Бенчмарки маскируют облака — сравнивать надо по чистому небу
(`scripts/exp_clearsky.py`). До второй строчки (0.779) не хватает **0.005 —
в пределах разброса сида**; формально третьи, фактически вровень с лучшим
европейским результатом при вдвое меньшей выборке. Prithvi на своих данных
недостижим и на наших проигрывает сети с нуля (запомнил 144 чипа). По степени
поражения полевые точности классических индексов — 59–73 %, наш mIoU 0.72.

**Чтобы честно обогнать 0.779**, нужен новый источник прибавки, не ансамбль:
SPEC-28 (многодатность), SPEC-30 (нормализация сцен), SPEC-27 (AF — для
итогового балла).

## 5. Как запускать

Машина: `ssh k8plus`, RTX 3090 24 ГБ, `~/fires` — зеркало репозитория
(синхронизация `rsync -az src/ scripts/ k8plus:~/fires/...`), `.venv/bin/python`.
Данные: `data/comp/train/{bs,af}`, `data/comp/test/{bs,af}` (только там!).
В памяти карты помещаются **две** обучающие задачи (по ~11 ГБ); третья —
OOM. Инференс при двух обучениях — тоже OOM: собирать на CPU
(`-E CUDA_VISIBLE_DEVICES=`, 5 сетей ≈ 20 мин, 11 сетей ≈ 40 мин).

Всё тяжёлое — под systemd:
```bash
systemd-run --user --quiet --unit=run-NAME -p MemoryMax=12G -p CPUQuota=400% \
  -p WorkingDirectory=$HOME/fires -p StandardOutput=file:$HOME/fires/logs/NAME.log \
  -p StandardError=inherit -E EPOCHS=200 -E DEPTH=7 -E WIDTH=32 -E CHANNELS=optical \
  -E JITTER=0.1 -E TAG=mytag .venv/bin/python scripts/exp_unet.py
```
Стенд `scripts/exp_unet.py` (обучение на 144, замер на 35): флаги через env —
`DEPTH WIDTH EPOCHS SEED CHANNELS=all|optical|context JITTER LOSS=dice|lovasz
BOUNDARY BDOU ARCH=plain|psp|ds|smp:<enc> RADNORM FOLD PSEUDO IGNORE_ZERO
FINAL=1` (FINAL — все 224 чипа, без замера, сохраняет `models/bs_unet_<TAG>.pt`).
Сохраняет `models/exp_<TAG>.pt`; печатает IoU одной сети без бустинга.

Замер в **общей шкале** (бустинг 0.4, правило SCL, под маской сеть):
```bash
CUDA_VISIBLE_DEVICES= .venv/bin/python scripts/exp_seeds.py models/exp_a.pt models/exp_b.pt ...
```
— строки «одна» и «накоплено N»; вероятности кэшируются в `models/exp_<tag>.tune.npy`,
повтор — секунды. Фильтр чужих пожаров в `exp_seeds` **не** применяется
(добавляет ≈ +0.017 IoU_burn); с ним — `scripts/exp_clearsky.py <tags>`.

Сабмит:
```bash
.venv/bin/python inference.py --data-dir data/comp/test --out submission_vN.csv \
  --template data/comp/test/sample_submission.csv --unet models/bs_unet_final_*.pt
```
Код возврата 0 = валидатор прошёл. Каждая версия — отдельный файл в
`submissions/` с индексом `submissions/README.md`; `submission.csv` в корне —
копия последней. Финальные модели: `models/bs_unet_final_d7*.pt` (9 на 19
каналах), `models/bs_unet_final_opt_*.pt` (5 оптических), `models/bs_hgb.pkl`,
`models/af_hgb.pkl`.

## 6. Как проверять

- `make gate` — прослеживаемость спек и receipt'ов, fail-closed.
- `python3 -m pytest tests -q` — 445 тестов.
- Валидатор сабмита локально: `src.comp.submission.validate(csv, sample_submission.csv)`.
- Каждый результат — строка в `evidence/hypotheses.md` с числами, и receipt в
  `evidence/receipts/SPEC-19/` с обязательными `limitations` и `non_claims`.
- Честность правил: подбор на одной половине 35 чипов, замер на другой
  (образцы: `scripts/exp_far.py`, `exp_sev2.py`, `exp_select.py`).
- Две пойманные ошибки измерения, не повторять: макро- вместо микро-усреднения
  (0.08 расхождения) и подбор порога внутри выборки (+0.14 мнимых).
