# REQ-003: Публичный доступ — REST API и веб-карта

## Summary

Результаты обоих конвейеров доступны без аутентификации через REST API
(GeoJSON/JSON) и веб-карту с двумя слоями и панелью отчёта по площади.

## Motivation

Целевая аудитория — лесхозы, региональные службы и волонтёры, у которых нет
доступа к ведомственным системам и нет ГИС-специалиста. Если результат доступен
только как файл на диске, проект не решает исходную задачу.

## Scope

**Внутри:** эндпоинты раздела 9 ТЗ, тайлы, фронтенд, экспорт CSV/GeoJSON,
`/api/v1/health`, служебный слой `/api/v1/flares`.

**Снаружи:** сами вычисления (REQ-001, REQ-002), развёртывание (REQ-005).

## Acceptance Criteria

- Вся агрегация выполняется на backend; фронтенд остаётся тонким клиентом.
- Каждый ответ, содержащий площадь, несёт вместе с ней `masked_fraction`,
  `thresholds_version` и `status` — потребитель API не должен иметь возможности
  получить голое число гектаров без контекста его достоверности.
- `/api/v1/health` различает «опрос прошёл успешно» и «получены новые данные»:
  это разные величины, и их смешение скрывает деградацию источника.
