# SPEC-7: Подбор пары сцен Sentinel-2 и расчёт dNBR/RBR

Status: planned

Requirement: REQ-002

Depends on: SPEC-6

## Summary

Ядро этапа 2: по завершённому событию (SPEC-6) найти пару сцен Sentinel-2 L2A
«до» и «после», рассчитать `NBR = (B8A − B12) / (B8A + B12)`, `dNBR` и `RBR`,
классифицировать тяжесть по порогам USGS и посчитать площадь в гектарах по
классам.

Четыре решения зафиксированы по результатам проверки данных (`docs/TZ.md` §6) и
отличаются от ред. 1 ТЗ:

1. **Каналы B8A + B12, оба 20 м.** Ред. 1 говорила абстрактно «NIR/SWIR», но
   фиксировала площадь пикселя 20 м; это согласуется только при B8A. B08 (10 м)
   потребовал бы ресемплинга и изменил площадь пикселя на 0.01 га.
2. **Пара из одного MGRS-тайла.** Разные тайлы — разные UTM-зоны и сетки;
   поэлементное вычитание без перепроецирования даст молча неверный результат.
3. **Двухступенчатый фильтр облачности вместо `eo:cloud_cover ≤ 20%`.**
   `eo:cloud_cover` относится ко всему тайлу 110×110 км; в сибирский сезон с
   дымом от самих пожаров порог 20% не оставит пар. Схема: сцена ≤60% → чтение
   окна SCL по bbox события → доля валидных пикселей внутри AOI ≥80%.
4. **Маска по SCL, не по s2cloudless.** Ассета CLP/CLM в Planetary Computer нет
   (проверено: B01–B12, B8A, SCL, AOT, WVP). Исключаемые классы SCL: 0, 1, 3, 8,
   9, 10, 11.

Сезонное ограничение: если окно поиска «после» исчерпано (полярная ночь севернее
~66°, снежный покров), событие получает статус `deferred` с датой возобновления.
Возврат нулевой или частичной площади в этой ситуации запрещён.

## Acceptance Criteria

- Пара сцен всегда принадлежит одному `s2:mgrs_tile`; попытка собрать пару из
  разных тайлов отклоняется. Тест на подставном каталоге с двумя тайлами.
- Отбор идёт двухступенчато; тест проверяет, что сцена с `eo:cloud_cover = 45%`,
  но чистая над AOI, **принимается**, а сцена с `eo:cloud_cover = 15%`, но
  закрытая облаком именно над AOI, **отклоняется**. Это ровно тот случай, который
  ломал исходную формулировку.
- Классы SCL 0, 1, 3, 8, 9, 10, 11 исключаются из статистики; тест на
  синтетическом SCL проверяет каждый класс.
- Площадь считается в нативной UTM-проекции сцены до перепроецирования. Тест
  сверяет площадь известного прямоугольника с аналитическим значением при
  пикселе 20 м = 0.04 га.
- Вместе с площадью всегда возвращается `masked_fraction`; ответ без неё
  невозможен по сигнатуре (не опциональное поле).
- Пороги классификации приходят из конфигурации и возвращаются как
  `thresholds_version` вместе с результатом.
- При исчерпанном сезонном окне возвращается `status="deferred"` с причиной и
  датой; тест на событии, завершившемся в ноябре севернее 66°.
- Пиксели со значением 0 в B8A или B12 трактуются как nodata, а не как
  валидный ноль.
