# SPEC-35: Пилот многодатных пар BS с контролем метки

Status: active

Requirement: REQ-006

Depends on: SPEC-28

## Summary

Пилот SPEC-28 до массовой выгрузки: проверить, разрешают ли метаданные однозначно найти дополнительные сцены и сохранить семантику маски. Новая дата не означает неизменность пожара. Используются только fit чипы, не tune/holdout/test. Сначала до 8 чипов; доступность сцены без проверки метки не считается успешной аугментацией.

## Acceptance Criteria

- Проверить CRS/bounds/даты, найти исходные и дополнительные сцены в том же MGRS через Planetary Computer. Записать item IDs, даты и пропуски.
- Для каждого пилотного чипа проверить фактическую привязку исходных данных к найденным сценам и отсутствие изменения периметра между post датами; при отсутствии проверяемых сведений сохранность метки обозначается unknown и чип не используется.
- Если есть не менее 4 пригодных чипов, обучить два сида с extra против повтора исходных пар с тем же числом шагов, неизменным tune и фиксированным контролем SPEC-32. Малый пилот не доказывает эффект расширения всех 224 чипов.
- Сигнал полезности .005 W; неподтверждённая привязка/маска — deferred с INSUFFICIENT_EVIDENCE, не выдуманное измерение.
- Продуктовый inference не получает новых входов.

## Frozen source-pilot decision

До замера прироста: безопасный первый вариант меняет только сцену pre, оригинальная post и маска неизменны. Это исключает перенос маски на более поздний развивающийся пожар. Установить соответствие исходной pre каталогу по B04/B8A/B12: correlation >=0.95 и RMSE отражения <=0.03 по общим валидным пикселям, покрытие >=90%. Дополнительная pre на том же MGRS, до исходной pre в пределах 30 суток; SCL invalid <=30%; медиана |NBR_extra-NBR_pre| внутри размеченной гари <=0.05. Выбирать ближайшую подходящую дату, не по результату модели. До 8 fit чипов, >=4 пригодных для обучения; вход заменяется с вероятностью 0.5 на каждом предъявлении, число шагов неизменно, контроль — исходные пары. Если пороги не пройдены, не ослаблять их после наблюдения. Это пилот стабильности baseline до пожара, не доказательство неизменности физической степени поражения.
