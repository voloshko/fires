# SPEC-33: Трудные отрицательные примеры AF с вложенной оценкой

Status: active

Requirement: REQ-007

Depends on: SPEC-19

## Summary

Проверить замену половины 1500 случайных отрицательных пикселей на трудные, сохраняя число примеров. Контроль — текущий HGB. Внутри каждого внешнего фолда вспомогательная модель добывает ошибки только на данных его обучения. Порог не подбирается на оцениваемом внешнем фолде. Минимальная полезная прибавка микро-F1 0.005.

## Acceptance Criteria

- 5 внешних фолдов тех же 336 train+val чипов, holdout 84 не читается.
- Для каждого внешнего фолда 20% его fit отделяются для настройки порога; добыча трудных примеров только на оставшемся fit. Контроль и кандидат имеют один fit, калибровку и внешнюю проверку.
- Все положительные + 1500 отрицательных/чип: контроль случайный; кандидат 750 случайных и до 750 наиболее уверенных отрицательных без повторов; при малом числе фона берётся весь.
- Сеть не нужна: CPU HistGradientBoosting, те же признаки/параметры. Общая сетка порогов 0.50..0.95 шаг .05, .95.. .995 шаг .005, .999. Сохраняются precision/recall/F1/TP/FP/FN, выбранный внутри порог каждого фолда.
- Отчёт включает обычную OOF-границу, выбранную по всему пулу, лишь как оптимистическую диагностику, отдельно от основной вложенной оценки.
- Парный bootstrap по чипам с фиксированным seed: 95% интервал дельты, оговорка о возможной зависимости чипов одного события. Рост >=.005 с нижней границей >0 — implemented; иначе rejected. Нет утверждений о закрытом тесте.
