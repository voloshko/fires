# SPEC-39: Устойчивое усреднение готовой BS-пятёрки

Status: rejected

Requirement: REQ-007

Depends on: SPEC-26

## Summary

Дешёвый CPU-эксперимент перед дедлайном: проверить, уменьшает ли влияние
уверенных одиночных ошибок усечённое среднее вероятностей пяти сетей v13/v15.
Новых весов, источников, тренировок и запросов к тесту нет. Проверяется один
заранее фиксированный вариант, без поиска весов или состава.

## Acceptance Criteria

- Контроль: среднее пяти сохранённых optical analog caches v13, те же 35
  development-чипов, HGB .4, SCL и drop_far=125. Контроль воспроизводит W
  .744275665 с допуском 1e-6. Хеши входов и кэшей сохраняются.
- Кандидат: отдельно для каждого пикселя/класса удалить минимум и максимум
  из пяти вероятностей, усреднить три оставшиеся, нормировать сумму классов
  к единице. Все остальные правила неизменны. Нулевая сумма — ошибка.
- До результатов критерий: delta W >=.005, положительная нижняя граница
  95% paired chip bootstrap (2000 повторов, seed20260918), положительные
  дельты в обеих половинах каждого из разбиений seed1/17/42. Половины
  проверяют устойчивость фиксированного правила, ничего по ним не выбирается.
- При провале rejected с FAIL receipt. При успехе implemented как
  development-результат; продукт и сабмит требуют отдельной проверки переноса.
- Только этот один вариант; не начинать перебор агрегаций после результата.
