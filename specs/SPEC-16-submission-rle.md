# SPEC-16: Кодирование RLE и валидация submission.csv

Status: planned

Requirement: REQ-007

Depends on: SPEC-15

## Summary

**Эта спека закрывается первой, до всякой модели.** Нулевой балл за раздел
метрики получает решение, для которого не удалось получить валидный
`submission.csv`, — а не решение со слабым сабмитом. Пока файл не собирается и
не проходит проверку формата, качество моделей не имеет значения.

Формат из постановки: кодировка UTF-8, разделитель запятая, первая строка —
заголовок, колонки `chip_id`, `class_id`, `rle`.

| Колонка | Тип | Содержание |
|---|---|---|
| `chip_id` | строка | Идентификатор чипа из `sample_submission.csv` |
| `class_id` | целое | Для AF всегда 1; для BS 1, 2 или 3 — степень поражения |
| `rle` | строка | Пары «начальный пиксель — длина» через пробел, в кавычках; пустая строка, если пикселей класса нет |

Правила кодирования: пиксели нумеруются построчно слева направо и сверху вниз,
**начиная с единицы**; пары идут по возрастанию начального пикселя; серии не
пересекаются и не соприкасаются; выход за пределы чипа не допускается.

Требования к содержимому: **447 строк без заголовка**, по одной на AF-чип и по
три на BS-чип; набор пар `(chip_id, class_id)` совпадает с шаблоном полностью,
порядок строк произволен; пропуски, `NaN` и пустые ячейки недопустимы; внутри
чипа маски разных классов не пересекаются.

## Acceptance Criteria

- Кодирование и декодирование взаимно обратны: `decode(encode(mask)) == mask`
  для случайных масок разной плотности, включая пустую и полностью заполненную.
  Тест на не менее чем 100 сгенерированных масках.
- Нумерация пикселей **с единицы и построчно**; тест сверяет кодирование
  известной маски с рассчитанной вручную строкой.
- Соседние серии сливаются в одну: «не соприкасаются» — часть формата, а не
  оптимизация. Отдельный тест на маске из двух смежных отрезков.
- Валидатор проверяет собранный файл против шаблона и **отвергает** файл с
  лишней или недостающей парой `(chip_id, class_id)`, с `NaN`, с пересечением
  классов внутри чипа и с выходом серии за пределы чипа. По тесту на каждое
  нарушение.
- Валидатор запускается как отдельная команда и возвращает ненулевой код
  возврата при любом нарушении: молча собранный неверный файл — худший исход.
- Собран валидный `submission.csv` на 447 строк **до появления любой модели**:
  тривиальные предсказания годятся, задача этой спеки — снять риск нулевого
  балла.
