# SPEC-89: Степень гибридом: граница C1-MM, градация dNBR, проверка на свежих 3 и 4

Status: implemented

Requirement: REQ-008

Depends on: SPEC-86

## Summary

SPEC-86 показал разделение ролей: одно-датная модель хорошо находит границу гари, но плохо
различает степень, а пороги dNBR наоборот. Гибрид задним числом дал mIoU_sev 0.345 против
0.180 и 0.133, но на той же проверке. Проверяем его честно.

**Гибрид (записан до замера, параметров не обучает)**: граница — C1-MM ≥ 0.5 (SPEC-82).
Внутри границы класс по dNBR: < 0.27 → «слабо», 0.27–0.66 → «умеренно», > 0.66 → «сильно»
(пороги USGS, как в SPEC-86; значения ниже 0.1 внутри границы тоже считаются «слабо»). Вне
границы — фон.

**Проверка — свежие наборы 3 и 4** (SPEC-76/78), окна с тяжестью MTBS (195 + 193). C1-MM их не
видел: он учился на HLS, свежем 1, EMS и FLOGA. Снимки «до» — как в SPEC-86. Метки и пиксели —
как в SPEC-86: MTBS 2/3/4 → 1/2/3, 6 и −1 → игнор, валидны оба снимка.

**Критерий**: mIoU по классам 1–3 пулом, бутстреп по окнам 1000, 95 %. Гибрид против одних
порогов dNBR — «лучше» / «хуже» / «вровень». Вторично: IoU по классам, бинарный IoU гари, по
наборам отдельно. C1-S здесь не меряется: он учился на этих окнах.

## Resolution

Receipt `evidence/receipts/SPEC-89/SPEC-89-HYB-001.json` (PASS).

| набор | гибрид mIoU_sev (слабо / умеренно / сильно) | dNBR mIoU_sev |
|---|---|---|
| свежий 3 (запад США), 195 окон | **0.296** (0.244 / 0.251 / 0.392) | 0.196 |
| свежий 4 (восток США), 193 окна | **0.153** (0.245 / 0.107 / 0.106) | 0.036 |
| **вместе, 388 окон** | **0.279** (бинарный 0.369) | 0.134 (бинарный 0.187) |

Гибрид − dNBR: **+0.146, [+0.114, +0.174] → лучше**, значимо на данных, которых модель
границы не видела. Разделение ролей подтвердилось: граница гари — по модели, градация — по
паре дат.

Решение: слой степени в оперативной карте — гибрид (C1-MM + dNBR внутри границы). Абсолютные
значения остаются низкими, градация по порогам USGS грубая; разметки степени для
Средиземноморья нет, поэтому на Кипре слой — оценка, а не проверенный продукт.
