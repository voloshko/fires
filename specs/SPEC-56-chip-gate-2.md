# SPEC-56: Гейт по чипу, вторая попытка: карта разногласия, новизна входа, качество пары

Status: rejected

Requirement: REQ-007

Depends on: SPEC-53

## Summary

SPEC-53 показал потолок стекинга по чипу +0.020 (оракул) и ноль у гейта на 8
признаках. Ресёч №3 (дополнение) называет три семейства признаков, которых не
было, и они разные по природе: (1a) **распределение карты разногласия** оптики и
сиама — среднее, доля > 0.3, 95-й процентиль, концентрация в предсказанной гари,
и взаимная информация членов (эпистемическая часть), а не скаляр согласия;
(1b) **новизна входа** — расстояние Махаланобиса сводки 25 признаков бустинга
(медианы и размах) чипа к обучающим чипам фолда; (1c) **качество пары** — дни
между сценами, смещение dNBR негоревшего (Parks), сдвиг освещения по устойчивым
пикселям. Stage 2 — плотность границы масок (форм-фактор 4πA/P², доля кромки,
число компонент) для оптики и сиама; прецедент только для выбора модели, для
взвешивания — нет, поэтому отдельно.

Гейт и протокол как в SPEC-53: HistGB глубины 2 → лучшая доля сиама на чипе,
LOFO по 5 групповым фолдам, затем 144 → 35. **Предзаявлено**: Stage 1 принят,
если закрывает ≥ 0.005 разрыва до оракула на фолдах **и** не ниже нуля на 35
чипах; Stage 2 остаётся, если добавляет ≥ 0.003 сверх Stage 1. Иначе разрыв
признаётся недостижимым по признакам чипа и гейт закрывается окончательно.
Stage 4 — бутстрэп по чипам (2000) для оракула и для потолка степени внутри
гари (+0.0235): если 95 % интервал потолка степени включает значения ниже 0.01,
работа над головой степени снимается.

Не делается: расстояние по признакам кодировщика сети (кэши хранят только
вероятности; сводка входных признаков — замена без переобучения), углы Солнца
(в метаданных чипов их нет).

## Acceptance Criteria

- `scripts/exp_chip_gate2.py` печатает три гейта (8 признаков / Stage 1 / Stage 1+2) на фолдах и 35 чипах, бутстрэп-интервалы, вердикты.
- Принято → гейт в `inference.py` (признаки без меток), v22. Отклонено → Resolution, леджер.

## Verification

- На k8plus: `CUDA_VISIBLE_DEVICES= OMP_NUM_THREADS=8 .venv/bin/python scripts/exp_chip_gate2.py`.

## Resolution

**Отклонено по предзаявленным критериям — обе ступени.** `exp_chip_gate2.py`, CPU по кэшам:

| гейт | фолды (LOFO) | по фолдам | 35 чипов |
|---|---|---|---|
| SPEC-53: 8 признаков | +0.0003 | +0.0006 / +0.0018 / +0.0019 / −0.0038 / +0.0006 | −0.0004 |
| Stage 1: + разногласие/MI, новизна, качество пары (18 признаков) | **−0.0011** | +0.0009 / −0.0013 / −0.0007 / −0.0041 / −0.0001 | −0.0014 |
| Stage 1+2: + плотность границы (24 признака) | −0.0002 | 0 / −0.0020 / +0.0006 / −0.0025 / +0.0029 | −0.0010 |
| оракул (лучшая доля по истине) | **+0.0197** | | +0.0062 |

Три новых семейства признаков из отчёта — распределение карты разногласия и
взаимная информация членов, расстояние Махаланобиса до обучающих чипов, дни между
сценами / смещение dNBR негоревшего / сдвиг освещения — не сдвинули гейт с нуля;
с 18 и 24 признаками на 144 чипах он стал чуть хуже восьми (переобучение).
Плотность границы не добавила ничего сверх Stage 1.

Бутстрэп по чипам (2000): оракул гейта +0.0197, 95 % интервал [+0.012, +0.029] —
резерв реален; потолок степени внутри найденной гари +0.0235, интервал
[+0.021, +0.026] — узкий, вопреки опасению отчёта, что он шумовой. Оба резерва
существуют и оба недостижимы имеющимися средствами: первый — потому что «какому
члену верить» не читается ни из входа, ни из разногласия, ни из качества пары;
второй — потому что степень разметчик ставил не по dNBR (SPEC-53/диагностика).

Гейт по чипу закрывается окончательно (две спеки, 3 набора признаков, 2 шкалы).
Не делалось: другие модели гейта — при отсутствии сигнала в признаках это не
поможет. Код продукта не менялся, v22 не собран.
