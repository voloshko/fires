# SPEC-86: Степень выгорания для леса и гор: 4 класса по MTBS против порогов dNBR

Status: active

Requirement: REQ-008

Depends on: SPEC-75, SPEC-82

## Summary

Для лесной службы степень важнее площади: по ней решают, где сажать и где ждать эрозии.
EMS даёт оценку ущерба в продуктах GRA, а наша модель для гор бинарная. Единственный
крупный открытый источник разметки степени — тематические мозаики **MTBS** (классы
«не сгорело / слабо», «слабо», «умеренно», «сильно», «позеленение», «маска»). Они
открыты через ImageServer `imagery.geoplatform.gov/.../USFS_EDW_MTBS_CONUS`, 30 м,
годы 1984–2024. Прямые ссылки на годовые архивы и пакеты по пожарам сейчас отвечают 404.

**Разметка (записана до обучения)**: для окон свежих наборов MTBS растр тяжести года
пожара вырезается в сетке окна (ближайший сосед). Классы: MTBS 2 → 1 «слабо», 3 → 2
«умеренно», 4 → 3 «сильно»; MTBS 0, 1, 5 → 0 «фон»; MTBS 6 и пиксели с меткой окна −1 →
игнор. Пожары 2025 года и позже (мозаик нет) выпадают. Уточнение до обучения: окно, где внутри
контура нет ни одного пикселя MTBS 1–5, исключается — MTBS тяжесть по этому пожару не
выпустил (найдено на пробном окне), и считать его фоном нельзя.

**Модель C1-S**: рецепт C1, голова на 4 класса, 3 сида. Потеря — взвешенная кросс-энтропия
[0.25, 1, 1, 1] плюс dice по «гари» (1 − p фона). Обучение — свежие наборы 1, 3, 4
(SPEC-72/76/78). **Проверка — свежий набор 2** (SPEC-74): эти окна не участвуют в обучении.

**Базовая линия — пороги dNBR по паре снимков** (как делают EFFIS и многие службы):
снимок «до» — `hls2-s30` того же тайла за 90 суток до возгорания с плохими пикселями
< 10 %. dNBR < 0.1 → 0, 0.1–0.27 → 1, 0.27–0.66 → 2, > 0.66 → 3 (USGS, Key и Benson;
два средних класса слиты в «умеренно»).

**Критерий**: mIoU по классам 1–3, пулом по пикселям проверки, бутстреп по окнам 1000,
95 %. C1-S (одна дата) против dNBR (две даты): «лучше» / «хуже» / «вровень». Вторично:
IoU по каждому классу, бинарный IoU гари, матрица ошибок.

**Продукт**: слой степени для карты Лимасола моделью C1-S (без разметки, демонстрация).
