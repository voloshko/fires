# SPEC-74: Второй свежий набор: веса смеси на первом, проверка на втором

Status: implemented

Requirement: REQ-008

Depends on: SPEC-72

## Summary

В SPEC-72 смесь пополам при пороге 0.5 оказалась не лучше Prithvi (−0.037). Веса и
порог там не подбирались, потому что подбирать было не на чем. Теперь есть на чём:
**второй свежий набор** из следующих пожаров того же хеш-порядка, не пересекающийся
с первым.

**Сборка**: `build_hls_fresh.py` с тем же рецептом SPEC-72. Пропускаются первые 320
пожаров хеш-порядка, просмотренные для первого набора. Берутся следующие 300 годных
окон, выход — `external/hls_fresh2/`.

**Протокол** (IoU гари по пулу, бутстреп по окнам второго набора, 1000 выборок, 95 %):
- на **первом** наборе выбираются: вес смеси w ∈ {0, 0.1, …, 1} и порог
  t ∈ {0.30, 0.35, …, 0.70} для P = w·C1 + (1 − w)·Prithvi; отдельно лучший порог для
  C1 и для Prithvi; «лучшая одиночная» — та из двух, что выше на первом наборе
  при своём пороге;
- на **втором** — один замер: подобранная смесь против подобранной лучшей одиночной.
  «Помогает», если разница > 0 и нижняя граница > 0; «вредит», если верхняя < 0;
  иначе «вровень».
- Повтор SPEC-72 на втором наборе (всё при 0.5) печатается рядом, не решает.

Если на первом наборе лучшим окажется w = 0 или w = 1, это уже ответ: смесь не
нужна. Замер на втором всё равно печатается.

## Resolution

Receipt `evidence/receipts/SPEC-74/SPEC-74-FRESH2-001.json` (INSUFFICIENT_EVIDENCE).

**Выбор на первом наборе**: смесь w = 0.3 (доля C1), t = 0.65 → 0.4863; C1 лучший
при t = 0.4 → 0.4119; Prithvi при t = 0.6 → 0.4746; лучшая одиночная — Prithvi.
Профиль по w: 0.475 (0), 0.481, 0.486, **0.486 (0.3)**, 0.472, 0.461 (0.5), … 0.412 (1).

**Проверка на втором (300 окон, общих пожаров нет)**: смесь 0.4590 против
Prithvi 0.4719 — **−0.013, 95 % [−0.028, +0.006] → вровень**. Выигрыш смеси на первом
наборе (+0.012) был подгонкой и на втором не повторился.

Повтор SPEC-72 на втором наборе (всё при 0.5): C1 0.360, Prithvi 0.461, смесь пополам
0.412. Здесь C1 − Prithvi = −0.101, [−0.159, −0.047] → **хуже**, значимо. Второй
набор подтвердил SPEC-72 с запасом.

Вывод: смесь нашего U-Net и Prithvi не нужна ни с равными, ни с подобранными весами.
