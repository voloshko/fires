# SPEC-54: Нулевой выстрел Prithvi-EO BurnScars на степных чипах

Status: rejected

Requirement: REQ-008

Depends on: —

## Summary

Первый шаг REQ-008: готовые веса Prithvi-EO-2.0-300M-BurnScars (6 полос HLS:
B2 B3 B4 B8A B11 B12, 30 м, бинарная гарь, IoU 0.875 на их тесте) прогоняются
**без дообучения** на наших 144 групповых чипах (сцена «после», 20 м → 30 м,
нормализация их means/stds). Цель — узнать, видит ли лесная модель степную
гарь вообще. Мерим IoU гари против нашей бинарной истины (степень > 0) на
чистом небе; сравниваем с одиночной оптической сетью соседа (0.618 взвешенно;
IoU гари одиночной сети — посчитать той же функцией). Сигнал остановки REQ-008:
IoU < 0.5. Данные и веса: `~/fires/external/` на k8plus (Apache 2.0, CC-BY-4.0).

## Acceptance Criteria

- `scripts/exp_prithvi_zero.py`: карты вероятностей гари по 144 чипам в двух вариантах (A — родные 20 м, B — пересчёт к 30 м), IoU гари на чистом небе по пулу и фолдам, потерянные пожары, **double-fault и Q с оптикой v21, сиамом v22 и бустингом SWIR** (findings-3: кандидат в смесь только при DF ниже удержанных 1.62–1.69 %); `research/prithvi-zero-v1/`.
- Решение предзаявлено: IoU ≥ 0.5 → REQ-008 продолжается (дообучение); DF с оптикой и сиамом ниже 1.6 % → отдельная спека на член смеси (дообучение на 4 класса, 5 фолдов); IoU < 0.5 — ставка на американские веса снимается, независимо от DF.
- В receipt `non_claims`: бинарно, без степени; 30 м против 20 м; сцена «после» без «до».

## Verification

- На k8plus: `.venv/bin/python scripts/exp_prithvi_zero.py`; PASS для продолжения REQ-008 — IoU гари ≥ 0.5 на пуле.

## Resolution

**Отклонено по предзаявленному сигналу остановки REQ-008 (IoU < 0.5).**
`exp_prithvi_zero.py`, 144 групповых чипа, сцена «после», 6 полос, их means/stds,
инференс 16 с на RTX 3090:

| член (один, argmax) | IoU гари, чистое небо | своя ошибка | потеряно пожаров | DF / Q с оптикой | DF / Q с сиамом v22 | DF / Q с бустингом |
|---|---|---|---|---|---|---|
| оптика v21 | 0.678 | 4.25 % | 24 | — | 1.86 % / 0.90 | 1.60 % / 0.68 |
| сиам v22 | 0.729 | 3.48 % | 18 | 1.86 % / 0.90 | — | 1.64 % / 0.71 |
| бустинг SWIR | 0.561 | 7.73 % | 27 | 1.60 % / 0.68 | 1.64 % / 0.71 | — |
| **Prithvi A, 20 м** | **0.219** | **31.1 %** | 106 | 2.01 % / 0.38 | 1.81 % / 0.37 | 4.07 % / 0.46 |
| Prithvi B, 30 м | 0.205 | 34.2 % | 109 | 2.05 % / 0.33 | 1.81 % / 0.33 | 4.10 % / 0.41 |

Лесная модель на степи не работает без обучения: IoU 0.2, ошибка на трети
пикселей чистого неба — она размечает гарью тёмную степь, пашню и тени, а
106 из 144 пожаров при этом не находит. По фолдам ровно (0.19–0.26), масштаб не
при чём (A и B почти одинаковы). Ставка «взять американские веса и докрутить»
в смысле REQ-008 **снимается**: докручивать нечего, модель не видит объект.

Побочная находка для смеси: ошибки Prithvi **почти не коррелированы** с нашими
членами (Q 0.33–0.38 против 0.68–0.90 между своими; DF с сиамом 1.81 % — ниже
удержанных 1.86–1.91 %). Это то самое «другое», которого смеси не хватает, — но
при собственной ошибке 31 % член бесполезен. Другая информация появится, только
если кодировщик Prithvi **дообучить** на наших 150 чипах на 4 класса; это уже не
«докрутка американских весов», а обучение с предобученным кодировщиком — тот
путь, который у соседа (SPEC-34, малый кодировщик на CEMS) проигрывал базе.
Решение об отдельной спеке — за пользователем; здесь оно не принимается.

Карты сохранены: `research/prithvi-zero-v1/probabilities_{A,B}.npy`, manifest с
порядком чипов. Не делалось: TTA, сцена «до» как второй кадр (у модели один
кадр), калибровка порога (при IoU 0.2 порог не спасёт — ошибка не в пороге).
