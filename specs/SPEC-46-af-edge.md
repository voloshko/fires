# SPEC-46: AF: осторожное расширение уверенных очагов

Status: rejected

Requirement: REQ-007

Depends on: SPEC-19

## Summary

Короткий CPU-пилот на готовом OOF v15: вернуть вероятные соседние пиксели
уверенного очага, не удаляя текущие детекции. Ожидание умеренное:
пространственная близость не гарантирует огонь.

## Acceptance Criteria

- 336 train/val чипов, кэш соседнего exp_af_incl.py valid, без FIRMS и test.
  Форма/порядок проверяются по sorted chip IDs, исходные y/valid совпадают
  с настоящими train-масками/валидностью. Контроль p>=.45 и valid должен
  воспроизвести F1 .9515 с допуском .0001. Хеши кэша/входов записываются.
- Единственный вариант, выбранный до результата: добавить валидные пиксели
  p>=.35 в окне 3x3 вокруг валидного p>=.75. Исходные детекции сохраняются.
  Фон за краем чипа не считается огнём. Порогов и окон больше не перебирать.
- Полезность: delta F1 >=.005, нижняя граница парного bootstrap по чипам
  >0 (2000, seed20260918), положительные дельты на обеих половинах каждого
  разбиения seed1/17/42. При провале rejected + FAIL receipt.
- При успехе это только development-пилот с pooled OOF baseline;
  абсолютная оценка оптимистична, независимость событий не доказана.
  Продукт и сабмит не меняются автоматически.

## Verification

- `OMP_NUM_THREADS=2 python scripts/exp_af_edge.py --out research/af-edge-v1.json`
- `make gate`; исходные counts и хеши в receipt SPEC-46.
- Не доказывает качество скрытого теста или независимую оценку v15.

## Resolution

Контроль F1 .951532 (TP7421, FP479, FN277), расширение .951565
(TP7446, FP506, FN252). +25 истинных и +27 ложных пикселей; delta
+.000033, CI95 [-.001117, .001119]. Половины дают противоположные знаки.
Критерий не пройден: SPEC-46-REPLAY-001 FAIL. Продукт и сабмит не менялись.
